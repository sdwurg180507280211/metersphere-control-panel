# 设计

用户已确认上一轮建议，本轮为 Design-First 的局部界面调整。

- `ServicesTab` 负责服务区收起状态、当前诊断服务和日志选择；不增加新的全局状态或 API。
- 抽出 `ServiceCard`，两行、72px 目标高度，按钮与状态分离。摘要复用现有观测语义，详细依赖留在诊断中。
- `ServiceDiagnostics` 改为原生 dialog 侧边面板，复用浏览器模态焦点管理和关闭返回焦点；不注册应用快捷键。
- `LogViewer` 增加可选选择回调，原生服务日志选择与卡片高亮同步，其他日志使用方不受影响。
- CSS 使用受限的服务区和占剩余空间的日志区。工具栏不随服务列表滚动；收起时保留展开入口。
- 用现有 node:test 验证摘要语义及 SSR 组件结构；隔离浏览器验证多种窗口尺寸、长错误、滚动、详情、日志选择和收起恢复。
- 不改变后端、配置、依赖、业务操作接口。与直接缩小字体相比，本设计通过减少常驻信息保证可读性。
