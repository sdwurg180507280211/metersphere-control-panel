# 一个项目，多个页面入口

## 修正范围（Bugfix）

当前错误：Event Q&A 的本地开发、线上提问、审核后台、iPad 展示被保存成四个项目，页面与项目的层级混淆。

预期：只保留 `event-qna` 一个项目及一套本地生命周期，在项目概览内提供本地和线上各三个页面入口。线上入口不依赖本地应用的状态。

继续保持：其他项目、默认 `accessUrl`、现有启动/停止/API、活动数据和线上版本均维持原有行为。

## 实现设计

- command 项目增加可选 `accessLinks`，每项包含 `label`、`url`、可选 `group` 和 `requiresRunning`。最多 20 项，只接受不含账号密码的 HTTP/HTTPS 地址。
- 配置服务原子保存；旧客户端未传 `accessLinks` 时保留已有入口，显式空数组才清除。
- 项目概览按组显示访问按钮；`requiresRunning=true` 的入口等待本地端口就绪，其他入口可独立访问。
- 项目配置可维护入口名称、分组、地址及本地运行要求。
- 已安装 App 更新后通过 API 合并 Event Q&A 配置，删除此前三个多余的快捷项目配置。
