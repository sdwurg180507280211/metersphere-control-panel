# 单窗口项目控制台

## 设计与范围

Design-First：将项目中心和 MeterSphere 工作区合并到同一应用窗口。

- 现状：MeterSphere 项目通过 IPC 打开第二个窗口；两套入口与状态生命周期割裂。
- 目标：左侧项目选择器切换上下文，同一窗口展示所选项目功能。MeterSphere 是一个项目选项。
- 保留：后端 API、配置格式、Job 生命周期、安全 IPC、外部浏览器访问、构建和打包行为。

## 交互规则

1. 默认进入 MeterSphere 服务管理，后续恢复上次选中的项目和 MeterSphere 页签。
2. 项目管理是窗口内页面；普通项目支持启动、停止、访问和配置，MeterSphere 保留现有全部功能。
3. 项目切换不会卸载已经访问的 MeterSphere 页面，保留 SQL 输入、筛选、结果和配置草稿。
4. 离开有未保存配置的页面需要确认，确认后草稿仍保留；关闭/刷新有草稿的页面也有保护。
5. WebSocket、后台任务提示、更新和通知属于应用层，不随项目切换而停止。后台任务提醒注明 MeterSphere。
6. 托盘和旧 openWorkspace IPC 通过同一窗口选择 MeterSphere。页面加载期间的请求保留至 Renderer ready。
7. 旧 view=hub、desktop=1 和 #services 等入口兼容；浏览器也使用统一控制台。
8. 项目列表读取失败保留当前选择并展示重试提示；已删除的选中项目回退到项目管理。

## 验收

- 项目切换、菜单栏入口和重复打开 IPC 只复用一个业务窗口。
- SQL 输入、配置草稿切走再返回仍存在；取消离开不改变项目选择。
- 构建/打包运行时切换到普通项目，后台状态仍可见并可回到对应功能页。
- 刷新、浏览器前进/后退、旧链接与已删除项目恢复正确。
- 弹窗支持 Escape、焦点约束与关闭后的焦点恢复；窄窗口导航可用。

当前仍只管理一套 MeterSphere 环境；多套 MeterSphere 实例不属于此次改造。
